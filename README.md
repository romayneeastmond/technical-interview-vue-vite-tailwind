A structured, end-to-end interview preparation system covering every phase of the modern job search — from the first recruiter call to signing the offer. Specifically designed for engineers pursuing **Engineering Manager** and **Technical Lead** roles at top-tier companies.

---

## 🌎 Live Demo

Live demo hosted on Vercel [Interview Prep](https://technical-interview-vue-vite-tailwi.vercel.app/#/).

---

## ✨ Features

- **4 Interview Modules** — Recruiter Screen, Hiring Manager, Technical Loop, and Offer & Negotiation
- **60+ Practice Questions** across all stages
- **STAR Answer Framework** for behavioral questions
- **UMPIRE Method** for technical problem-solving
- **Salary & Equity Negotiation** scripts and tactics
- Responsive design with smooth animations

## 🗂️ Modules

| #  | Module              | Focus                                               |
|----|---------------------|-----------------------------------------------------|
| 01 | Recruiter Screen    | Elevator pitch, salary expectations, fit signals    |
| 02 | Hiring Manager      | STAR behavioral stories, leadership, conflict       |
| 03 | Technical Interview | Algorithms, system design, live coding etiquette    |
| 04 | Offer & Negotiation | Counter-offer scripts, RSU/equity, competing offers |

## 🚀 Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build for production

```bash
npm run build
npm run preview
```

## 🛠️ Tech Stack

- **[Vue 3](https://vuejs.org/)** — Composition API with `<script setup>`
- **[Vite 5](https://vitejs.dev/)** — Lightning-fast dev server and build tool
- **[Vue Router 4](https://router.vuejs.org/)** — Client-side routing
- **[Pinia 2](https://pinia.vuejs.org/)** — State management
- **[Tailwind CSS 3](https://tailwindcss.com/)** — Utility-first styling
